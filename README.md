# Monogame-Platformer

2D platformer roguelite on the Monogame Framework

## Running
Use VS 2019 or VS 2017 with monogame installed
Open as a VS project and run as debug from the IDE

## Features
* Platforming and Custom Levels
* Custom Particle System 
  * Blood that you can shoot from characters
  * When shooting, you lose health
* Enemies
  * Runner
  * Darter
* Custom tile and Mapping From scratch
